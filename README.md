# Sree Ranganadha Jewellers

Premium responsive showcase website for Sree Ranganadha Jewellers, built as a portable static site.

## Run it

Open `index.html` in a browser, or serve this directory with any static host / local preview extension. The typography and Lucide icon library load from their public CDNs, so an internet connection makes the visual experience complete.

## Included interactions

- Fully bilingual Telugu-first / English-supporting luxury storefront with animated collection filters
- 18 enquiry-ready collection cards across bridal, gold, everyday, silver, gifting and men's jewellery
- WhatsApp enquiry form and persistent chat button, using `+91 93927 38383`
- Maps search link based on the supplied Kollabazar / M.G. Road address
- Refined crest treatment and owner story using both supplied proprietor portraits
- Owner admin dashboard for business details, message, phone number and product collection cards

## Admin access

1. Select **Owner admin** in the footer.
2. Enter starter passcode `SRJ2026`.
3. Update content in the dashboard. Changes are stored in that browser's local storage.

This is a client-preview admin layer, rather than a server-side secure CMS. Before a public launch, connect authentication and a database / media store, then replace the placeholder product photography and the exact Google Maps pin. The admin dashboard includes a launch checklist for this handoff.
